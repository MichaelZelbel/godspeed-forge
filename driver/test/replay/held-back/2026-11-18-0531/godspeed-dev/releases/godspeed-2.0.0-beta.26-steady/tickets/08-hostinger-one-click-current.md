Ticket for 2.0.0-beta.26 (plan item 8). Size: light. Depends on: nothing. Repository: MichaelZelbel/godspeed-mission-control. Issue: #663. Michael keeps the one-click button (2026-11-16).

## Problem
The Hostinger one-click button on godspeedmissioncontrol.com/hostinger points at commit `78ea790d`, whose `docker/hostinger/one-click.yaml` pins the image of 2.0.0-beta.6. A buyer gets beta.6. The one-line server installer refuses to touch a one-click install, so that buyer has no way forward from inside Godspeed.

## Why
Everyone who installs Godspeed should get the current public version.

## Why now
The maintainer found it on 2026-11-16 while bringing his book level with beta.24.

## Outcome
`docker/hostinger/one-click.yaml` names the image of the version the public line serves, and stays current with every release without a hand edit.

## Invariants
- The file is generated by `docker/hostinger/installer/public-compose.mjs`, never edited by hand, and still holds no buyer credentials or setup fields.
- The image is named by its immutable digest.
- Blocks: a finding that breaks the outcome, an invariant or the acceptance on a normal install (files as the installer writes them, read by the user it runs as), and any finding, on any install, that leads to an unsafe or outward action nobody approved. A fault that needs a damaged or hand-edited file, wrong permissions or a rare race, and whose worst effect is safe (a missed or late notice, an extra question, a visible failure), is written into the pull request as a limit and does not block.

## Acceptance
- `public-compose.mjs` takes the released version's image digest (the one the public stage names) as its input and writes the file from it.
- A check fails when `one-click.yaml` on a branch names an image other than the released one. The release step runs it on `beta` after promoting.
- `docker/hostinger/test.sh` (or the repository's existing Hostinger tests) passes.

## Done means
The generator change and the check exist and pass with the repository's tests. Promote regenerating the file on `beta` is the release step's part, and the website's link is Mission Control's.
