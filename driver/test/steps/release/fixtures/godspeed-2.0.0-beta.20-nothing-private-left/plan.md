# Godspeed 2.0.0-beta.20: nothing private left

A trimmed copy of one real plan, kept as a fixture: only the part the standing-waiver test reads.

A failed scenario job is blocking when its name contains one of these phrases (the release tools read the list).

**Blocking scenarios:**

- Docker and Linux import made-up Hevy workouts (workouts-from-hevy, item 2)
- an overnight remembered-facts routine files one day once (day-becomes-facts, item 3)
- a Hermes update keeps good and rolls back broken releases (hermes-update-rollback, item 4)
- turns a first goal into useful work and a matching Telegram brief (first-day: the proof of #275, carried here from the withdrawn 2.0.0-beta.18.1 by its withdrawal note, with its job added by the release step)
- a talk says when its preparation did not pass, and opens from one that did (talk-prep-honest: the proof of the coach talk record #319, which this release's README ships)

Every other scenario job that fails (the Charm Challenge, the Telegram and brief jobs, the
update and connection-check jobs, the video-skills job and the rest) is named in the result with its
cause and does not block. The workflow's summary job ("the verdict") follows the others.
