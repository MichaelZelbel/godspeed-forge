# Set up the Forge

Extract only the `owner/repository` name from the owner's request. Run:

```bash
godspeed-forge setup owner/repository
```

Relay the command's messages exactly. Let the owner complete each GitHub browser step and answer
the two mission questions. Do not request or repeat a key, token, App id, or private key.
